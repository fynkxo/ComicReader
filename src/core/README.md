# 核心业务逻辑层（C++）

本目录用于存放漫画阅读器的核心业务逻辑模块，与 UI 层（QML）解耦。

规划的子模块：

| 目录        | 职责                                                          |
| ----------- | ------------------------------------------------------------- |
| `archive/`  | 档案解析器（zip / cbz / rar / cbr / 7z / cb7 / tar / pdf / 文件夹） |
| `rendering/`| 渲染与图像处理（Tile 渲染、双页拼页、裁剪、滤镜、着色器）    |
| `database/` | SQLite 数据管理（阅读历史、书签、收藏夹、标签）               |
| `metadata/` | ComicInfo.xml 元数据解析与本地索引                            |

> 说明：当前为工程骨架阶段，以上模块将在后续路线图阶段逐步实现。
